# Security policy

## Reporting a vulnerability

If you find a problem, for example an instruction in the skill that could make an agent leak data
or run something unsafe, report it privately through GitHub's
[private vulnerability reporting](https://github.com/maumoya/crawlhound/security/advisories/new).
You will get an answer within 7 days.

## Supported versions

Only the latest version on `main` is supported.
